# 美術簡報：小島樂園角色重新設計

你是這款遊戲的**美術總監兼角色設計師**。請重新設計玩家角色的臉型、五官、體型與模型構造，產出設計稿。現在的角色審美不合格，請大膽重做，不必保留現有設計。

## 遊戲

- 「小島樂園」是瀏覽器 3D 多人散步遊戲（three.js）。玩家捏一個自己，在陽光小島上散步、揮手、比愛心，同時最多 16 人。
- 鏡頭是第三人稱斜上方俯視，角色在畫面上大約 80–160 像素高。捏臉畫面裡角色會放大到 300–500 像素高。
- 想要的感覺：療癒、可愛、溫暖的生活模擬遊戲，像《動物森友會》玩家角色那種大頭 Q 版人類。**這是原創設計，不要複製任天堂的任何角色或造型**，參考的是「類型」與氛圍。
- 場景是 Kenney CC0 的低多邊形模型（椰子樹、木屋、碼頭），色調明亮、飽和、偏暖。角色要和場景搭配，但可以比場景更圓潤精緻。

## 技術限制（設計必須做得出來）

角色要能「捏」，所以不能是一個固定模型，必須拆成可替換的零件：

1. **頭部**：可以是任何程式能產生的形狀，例如旋轉體（lathe 輪廓線）、變形過的球、多個形狀組合。請給出輪廓的具體描述或座標點。
2. **臉**：五官畫在一張貼圖上，貼在頭部正面。所以五官是 2D 手繪風（像貼紙），請給出每種五官的畫法與在臉上的位置比例。
3. **頭髮、帽子、耳朵、眼鏡**：獨立網格，用簡單幾何（球、殼、圓錐、管、旋轉體、擠出形狀）組合。請描述每種髮型的構造方法。
4. **身體**：軀幹、手臂、手、腿、鞋各自獨立，才能走路擺動。服裝顏色與花紋可換。
5. 單色或簡單貼圖的材質，柔和光照。不能用外部模型檔或骨架動畫。

## 交付物（全部放到 `design/`）

1. **`design/DESIGN.md`**：設計文件，用繁體中文寫：
   - 對現況的批評（具體到哪個部位、為什麼）。
   - 整體風格方向與關鍵詞。
   - **體型比例**：以「頭高」為單位的比例表，並換算成公尺（角色總高約 1.2–1.5 m，你決定）。頭、脖子、軀幹、手臂、手、腿、腳的尺寸與位置。
   - **頭型**：形狀描述與輪廓座標（例如側面輪廓的點列），臉頰、下巴、後腦怎麼處理。
   - **臉部配置**：眼睛、眉毛、鼻子、嘴巴、腮紅在臉上的位置（以臉寬、臉高的百分比表示）、大小、間距。
   - **五官選項**：每種眼睛、眉毛、鼻子、嘴巴的畫法（形狀、線條粗細、亮點位置），建議的選項數量與名稱。
   - **髮型**：8–10 種，每種的構造方法（用哪些幾何、大小、位置），以及怎麼避免蓋住臉。
   - **服裝與配件**：上衣、下身、鞋、帽子、眼鏡的構造。
   - **色票**：膚色、髮色、眼睛、服裝的 hex 色碼。
   - **材質與光照建議**：粗糙度、要不要描邊、陰影色調等。
2. **`design/spec.json`**：上述數字的機器可讀版本（比例、座標、色票、選項清單），讓程式可以直接照著做。
3. **設計稿圖片**（用你的生圖工具，乾淨的淺色或純色背景，每張都是同一個角色風格）：
   - `design/01-turnaround.png`：基本體型三視圖或四視圖（正面、3/4、側面、背面）。
   - `design/02-face-parts.png`：五官選項表（各種眼睛、眉毛、鼻子、嘴巴、腮紅）。
   - `design/03-face-shapes.png`：臉型與表情（一般、眨眼、開心、驚訝等）。
   - `design/04-hairstyles.png`：所有髮型一覽。
   - `design/05-outfits.png`：服裝、帽子、眼鏡一覽。
   - `design/06-lineup.png`：6 個用這套系統捏出來的不同玩家站在小島上，展示多樣性。
   - 每張圖如果一次畫不好，可以重畫，挑最好的一張。圖裡的設計要和 DESIGN.md 的數字一致。

完成後，請在 `design/DESIGN.md` 最後列出每張圖的檔名與內容說明。
