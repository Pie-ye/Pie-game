# 審稿一：暖蘋果第一版

色票、三頭身、短脖子、大條紋、眼鏡尺寸都跟上了。從 `01-turnaround.png` 和六人排隊看，這一版仍像一顆頭皮球扣了薄髮片：兩側光頭、耳朵全露出來、五官貼在球面上。120 px 時最先消失的就是「這是誰的頭髮」。

`design/spec.json` 已改成 **version 2**。`DESIGN.md` 的頭型與髮型段改成跟它同一套數字。程式下一版以 spec 為準。球的 `scale` 是各軸**半徑**（公尺），跟現在 `mesh(G.ball)` 一樣。膠囊的 `length` 不含兩端半球。

示意圖：

- `review1/markup-front.png`：小麥芽正面，標了下面第 1–8 項。
- `review1/hair-short-cap.png`：短圓蓋的側視和正視，標瀏海下緣 `y=0.062` 和髮尾 `y=-0.15`。

頭的座標都是頭心本地，原點在世界 `y=1.15`。`+Y` 朝上，`+Z` 朝前。

## 規格改了什麼

- 髮型 10 種全部重寫。短圓蓋是包到下顎的厚殼加厚瀏海，不再是 `y>0.07` 的頭蓋。
- 變形加了額收窄。蘋果臉 `foreheadNarrow=0.24`，頰外推改成 `0.034`。正面輪廓半寬改成額 `0.11`、頰 `0.22`。
- 臉禁區的上緣改到 `y=0.04`。瀏海下緣固定在 `y=0.062`。
- 圓圓眼、閃亮眼、睫毛眼的虹膜直徑改成眼高的 `0.85`。眼寬、眼高改成臉的 `28%`。微笑寬度改成 `26%`。
- 連指手套改回寬 `0.10`、高 `0.086`、深 `0.062`，膚色往 `#E07860` 混 `20%`。
- 鞋改成寬 `0.104`、高 `0.12`、長 `0.16`，加靴口。短褲下緣降到世界 `y=0.36`。
- 連身裙下擺降到 `y=0.18`。帽 T 加一圈從正面看得到的領。帽子坐在頭髮上，不把髮型刪掉。

## 前 10 個問題

### 1. 頭髮是頭蓋，兩側是頭皮

`look0` 到 `look4` 的正面和背面都一樣：髮色只蓋住頭頂，太陽穴、耳朵、後腦下半是膚色。`showcase` 上排第一人的背面是一顆皮膚球扣了一片焦糖蓋。設計稿的短圓蓋是包住兩側、收到下顎的蓬鬆短髮，加上貼著眉毛的厚瀏海（`01-turnaround.png`、`04-hairstyles.png` 左上）。

現在 `addHair` 的 `cap(0.07)` 只留 `y>0.07`，外偏預設 `0.03`。這就是第一版規格寫錯的地方，程式照著做了。

改法：每種頭髮都做成有厚度的殼，不要單層開面。

- 外殼沿法線外偏 `outer`，內殼外偏 `inner`（約 `0.010`）。
- `keep(x,y,z)` 看的是**還沒外推**的頭頂點，三個頂點都通過才留這個三角形。
- 內殼反面，把開口縫起來。厚度是 `outer-inner`，短髮約 `0.038`。
- 人耳：`ears: hide` 的髮型不要畫人耳。`notch` 的髮型在耳位挖空：`|x|>0.165 && y<0.045 && y>-0.09 && z>-0.05 && z<0.07`。
- 光頭的人耳縮放改成 `(0.030, 0.055, 0.016)`。現在是 `(0.022, 0.050, 0.036)`，前後厚了一倍。

短圓蓋的數字在下一節。十種都要換，參數表在後面。

### 2. 臉沒有打平，五官還是貼在球上

`headShape` 把規格的 `z = z * 0.62 + 0.05` 改成只壓 `z>0.1316`。球最前點 `z=0.181` 兩邊算完都約 `0.162`，可是頰側 `z=0.10` 完全沒動。規格會把它推到 `0.112`，整張臉收到同一個平面。現在俯視時眼睛還是沿著球面往下掉。

`face.js` 的 `drawFace` 把畫布清成透明。眼瞼用 `destination-out` 挖掉的地方，露出的是受光的球面，所以眼睛像貼紙。規格要臉片先填那一檔膚色，外圈 `6%` 羽化。

改 `character.js.txt` 的打平，對每個 `z>0` 的頂點：

```js
z = z * 0.62 + 0.05;
```

然後才做額往後、額收窄、推頰、收下巴、圓後腦。臉部材質維持 Standard、roughness `0.92`，`emissiveIntensity` 用 `0.4`。

### 3. 額頭和臉頰一樣寬，蘋果臉沒有出來

球在本地 `y=0.14` 的半寬約 `0.167`。設計的正面輪廓這裡是 `0.11`，頰才是最寬。現在頭的剪影是正圓，再被兩邊的大耳朵加寬。

蘋果臉在額往後之後加：

```js
if (y > 0.04) x *= 1 - 0.24 * smooth(0.04, 0.20, y);
```

圓臉係數 `0.10`，小瓜臉 `0.30`。頰的高斯維持中心 `(±0.12, -0.02, 0.06)`、`σ=0.07`，外推改成 `0.034`。驗收看正面輪廓，半寬對上這些點、誤差 `8 mm` 以內：

`(0.05, 0.22) (0.11, 0.14) (0.17, 0.05) (0.22, -0.02) (0.17, -0.12) (0.10, -0.19) (0.03, -0.22)`

### 4. 瀏海是一顆扁透鏡，停得太高

`bangs()` 的球心在 `y=0.115`，半徑高 `0.038`，下緣約 `y=0.077`，寬只有 `0.28`。眉毛在 `y≈0.055`，中間空出一條額頭，兩側太陽穴沒有頭髮。設計稿的瀏海是一整條厚的，下緣幾乎貼著眉。

短圓蓋的瀏海用第二層殼，不要用那顆扁球：

- `outer 0.056`，`inner 0.014`
- `keep`: `z>0.02 && y>=0.062 && y<0.17 && |x|<0.175`

下緣全頭統一是 `y=0.062`。眼睛上緣大約在 `y=0.04`，中間留 `2 cm` 給眉毛。

### 5. 虹膜太小，嘴也短

`face.js` 把眼白橢圓的 `rx` 乘了 `0.9`，虹膜再用 `min(rx, ry) * 0.62`。以現在的眼高 `25%`（136 px）計，虹膜直徑約 `74 px`，只佔眼高的 `54%`。`02-face-parts.png` 的圓圓眼幾乎被虹膜填滿，白邊只是一圈。

`eye()` 改成：

- 眼白橢圓用完整的眼寬、眼高，去掉 `0.9`。
- `ir = eyeHeight * spec.iris / 2`。
- 圓圓、閃亮、睫毛：`iris=0.85`，`pupil=0.42`，高光直徑 = 眼高的 `0.28`，上眼瞼只蓋 `0.06`。
- 瞇瞇眼虹膜也是 `0.85`（眼高仍乘 `0.72`）。杏仁 `0.74`，下垂 `0.80`，星星 `0.88`，豆豆維持 `0.38`。

版面：眼寬 `28%`、眼高 `28%`，中心仍是 `x=31/69`、`y=40`。微笑寬度 `26%`（現在 `20%`），嘴的中心改到臉高 `74%`。

### 6. 袖子是浮在肩上的圓柱

`G.sleeve` 是半徑 `0.066`、長 `0.085` 的圓柱，放在上臂本地 `y=-0.03`。`look0` 的肩線有一圈皮膚縫，袖口像兩塊白貼片。連身裙把這截袖子畫成內搭的米白色（`vest || dress ? underM`），黃裙上就更明顯。

袖子改掛在肩關節上，用旋轉體，本地剖面 `(y, r)`：

`(0.02, 0.086) (-0.02, 0.070) (-0.09, 0.056)`

`y=0.02` 那一圈埋進軀幹。連身裙的袖子用裙子的顏色。背心維持無袖，裡面那件米白衫用同一條剖面。

### 7. 手是直立的蛋

手套現在是 `mesh(G.ball, …, 0.034, 0.050, 0.043)`，也就是寬 `0.068`、高 `0.100`、深 `0.086`。規格的連指手套是橫向的：寬 `0.10`、高 `0.086`、深 `0.062`。拇指又是一顆半徑 `0.024` 的整球。120 px 時手和手腕是同一塊。

改成單位球縮放 `(0.050, 0.043, 0.031)`，中心在手局部 `(0, -0.048, 0.008)`。拇指縮放 `(0.018, 0.016, 0.014)`，往身體中線 `0.012`、比掌心高 `0.020`、往前 `0.020`，三分之一埋進掌心。顏色是膚色往 `#E07860` 混 `20%`，roughness `0.72`。

### 8. 鞋跟小腿一樣細，小腿是兩根管子

鞋是 `CapsuleGeometry(0.042, 0.068)`，半徑和脛骨 `0.05` 差不多，沒有靴口。短褲下緣在世界 `y≈0.40`，鞋面在 `y≈0.085`，中間 `0.3 m` 都是皮膚管。設計稿的靴子又寬又高，短褲和靴口之間只有一截。

鞋改成單位球縮放 `(0.052, 0.048, 0.080)`，世界中心 `(±0.078, 0.065, 0.03)`，尺寸是寬 `0.104`、高 `0.12`、長 `0.16`。底下加鞋底盒 `0.108 × 0.020 × 0.155`，顏色是鞋色的 `72%`。開口加圓環，半徑 `0.055`、管徑 `0.016`。短褲改到髖以下、世界 `y=0.36` 收口，環的管徑 `0.014`、半徑 `0.07`。

### 9. 帽子把頭髮吃掉

`look1` 的草帽下是光頭，雙丸子被 `if (!hatted)` 刪掉。設計稿的丸子露在帽簷兩側。`look3` 的毛帽是 `headShell(offset 0.05, y>0.05)`，把刺刺頭全蓋成一頂綠頭盔。`look4` 的棒球帽是 `y>0.075` 的穹頂，下面只剩一條沒接上的金髮。帽簷程式用了半徑 `0.33`，規格原本是 `0.30`。

帽子坐在第 1 項的外殼上。瀏海、側髮、後髮都留著。只收進帽子的是翹毛，以及底部位於 `y>0.15` 的錐。

- 草帽：帽簷半徑 `0.28`、厚 `0.012`、上掀 `12°`。丸子改放到 `(±0.185, 0.11, -0.02)`，半徑 `0.060`，露在冠的外面。冠半徑仍是 `0.16`。
- 毛帽：殼只留 `y>0.10`，外偏 `0.036`。帽沿圓環在 `y=0.09`，管徑 `0.026`。球頂半徑 `0.045`。刺刺頭的側錐和太陽穴絨球留在帽沿下面。
- 棒球帽：殼的條件改成 `y>0.07 && z<0.10`，外偏 `0.032`，額髮和後頸留在外面。帽簷尺寸 `(0.18, 0.012, 0.09)`，中心 `(0, 0.07, 0.16)`，上掀 `18°`。

### 10. 帽 T 從正面看不見帽子，連身裙像燈罩

`look5` 的帽 T 只有兩條白繩。帽子是半徑 `0.12` 的球，放在 `z=-0.10`，被鮑伯頭擋住。連身裙下擺在 `y=0.30`，下面兩條腿像柱子。設計稿的黃裙收到靴子上方，帽 T 的領口一圈看得到。

帽 T 加領圈：圓環半徑 `0.090`、管徑 `0.028`，世界位置 `y=0.90`、`z=0.02`。腦後的帽兜改成半徑 `0.16` 的球，縮放 `(1.1, 0.85, 0.80)`，中心 `(0, 0.98, -0.12)`，朝前的半球切掉。白繩留著。

連身裙裙片：`y=0.62` 半徑 `0.15`，收到 `y=0.18` 半徑 `0.22`，Z 仍乘 `0.82`。袖子用第 6 項，顏色跟裙子相同。

## 十種髮型

共同的臉窗，短髮殼都要挖掉：

```text
FACE = z > 0.015 && y < 0.062 && Math.abs(x) < 0.15
NOTCH = Math.abs(x) > 0.165 && y < 0.045 && y > -0.09 && z > -0.05 && z < 0.07
```

有草帽、毛帽、棒球帽時，不要刪殼、不要刪瀏海。只隱藏標成翹毛的那一顆，以及底高過 `y=0.15` 的錐。

### 短圓蓋

包到下顎的蓬鬆短髮。人耳隱藏。這就是三視圖那一頭。

- 殼：外 `0.048`、內 `0.010`。`keep`: `y > -0.15 && !FACE`
- 瀏海殼：外 `0.056`、內 `0.014`。`keep`: `z > 0.02 && y >= 0.062 && y < 0.17 && |x| < 0.175`
- 下顎側蓬，左右各一：球心 `(±0.195, -0.03, 0.02)`，半徑 `(0.052, 0.086, 0.062)`
- 翹毛：球心 `(0.02, 0.255, 0.02)`，半徑 `(0.022, 0.040, 0.020)`，`rotation.z = -0.55`。戴帽時收進帽子。

### 旁分

比短圓蓋稍短，`+X` 側分開，`-X` 側髮量較多。人耳用 `NOTCH` 露出來。

- 殼：外 `0.044`、內 `0.010`。`keep`: `y > -0.12 && !(z > 0.02 && y < 0.062 && x > -0.04 && x < 0.16) && !NOTCH`

- 重側的量：球心 `(-0.10, 0.13, 0.06)`，半徑 `(0.07, 0.045, 0.05)`
- 短鬢角：膠囊半徑 `0.030`、長 `0.07`，中心 `(0.205, -0.03, 0.02)`
- 長鬢角：膠囊半徑 `0.038`、長 `0.12`，中心 `(-0.205, -0.05, 0)`

### 鮑伯

- 殼：外 `0.050`、內 `0.012`。`keep`: `y > -0.17 && !(z > 0.02 && y < 0.062 && |x| < 0.12)`

### 雙丸子
