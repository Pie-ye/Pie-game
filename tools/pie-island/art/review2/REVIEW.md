# 審稿二：暖蘋果第二版

大虹膜、短脖子、長裙、連身裙同色袖、帽 T 的白繩，都留對了。2.4 m 鏡頭下還是同一件事：頭髮是一頂頭盔，肩膀兩顆氣球，腳是兩根管子。六個人站在一起，髮型剪影分不開。

兩處偏離，一處留、一處退：

- 臉打平的 `+0.05` 在 z 0→0.06 漸入，留著。硬加在 z=0 會斷出 5 cm 台階。量下來臉最前仍是 z≈0.162，平臉成立。
- 額收窄減半（蘋果 0.12、圓臉 0.05、小瓜臉 0.15）留著，不要改回 0.24。頭頂多加的 70% 厚度拿掉。理由和數字在第 1 項。

頭的座標仍是頭心本地，原點在世界 y=1.15。`+Y` 朝上，`+Z` 朝前。球的 `scale` 是各軸半徑（公尺）。

## 前 8 個問題

### 1. 頭頂加厚 70% 把每種頭髮做成頭盔

`headShell` 裡 `lift = 1 + 0.7 * smooth(0.02, 0.2, y)`，到頭頂是 1.7。短圓蓋外偏 0.048 在頭頂變成 0.082。毛帽、棒球帽又把 `style.outer * 1.7` 當底再乘一次這條 lift，帽冠被推出 16 cm。`look0` 到 `look5` 的正面都是一顆圓蓋扣在臉上，切邊一圈鋸齒。三種頭型的差別也被這層圓蓋吃掉，`creator.png` 選了小瓜臉，輪廓仍和蘋果臉一樣。

0.24 收不回設計稿的額寬，還會把臉片拆掉，所以不要加回去。球先縮放再收，蘋果臉在 y=0.14 的半寬：

| 收法 | y=0.14 半寬 | y=0.22 半寬 | 頰 y=−0.02 |
| --- | --- | --- | --- |
| 現在 0.12，收到頭頂 | 0.162 | 0.074 | 0.222 |
| 規格 0.24，收到頭頂 | 0.149 | 0.064 | 0.222 |
| 設計稿輪廓 | 0.11 | 0.05 | 0.22 |

臉片半寬是 0.16（0.32 m 那張）。半寬收到 0.15 以下，額頭兩側的射線打不中頭，`headShape` 會把那些頂點的 z 設成 0，臉片從兩太陽穴塌進頭裡。設計稿那個 0.11 是瀏海底下露出來的皮膚，不是頭殼要收到的寬度。

改法：

- 刪掉 `lift`。外偏就是參數 `outer`，內偏就是 `inner`，沿法線，到頭頂不再加厚。
- `SHAPES` 的 `narrow` 維持 0.12／0.05／0.15。額帶的強度跟現在一樣，y=0.16 以上收到 0，頭頂不再越收越尖：

```js
if (y > 0.04) {
  const k = smooth(0.04, 0.20, y) * (1 - smooth(0.16, 0.22, y));
  x *= 1 - s.narrow * k;
}
```

y=0.14 的半寬仍是現在的 0.162，臉片接得住。y=0.22 的係數是 0，半寬回到 0.084。小瓜臉靠 `scale (0.94, 1.16, 0.84)` 就會比蘋果臉高，不必再靠頭髮的厚度來分。

切邊的鋸齒是開口三角形的法線斷掉。殼縫好之後，找出只被一個三角形使用的邊，那些頂點是邊緣：

- 外層頂點沿法線收回 6 mm，再 `y -= 4 mm`
- 內層頂點沿法線推出 4 mm

邊緣變成約 8 mm 的圓口，短髮下緣、瀏海底、帽冠的切口都用同一套。

### 2. 瀏海是第二層厚殼，翹毛埋在殼裡

短圓蓋的第二個 `headShell`（外 0.056）在 y=0.062 切一刀，兩側停在 `|x|=0.175`。lift 還在的時候，這層在 y=0.17 厚到 9 cm，正面就是一塊帽簷，太陽穴是空的。`04-hairstyles.png` 的短圓蓋是一排軟的、下緣貼著眉、左右接到側髮的瀏海，頭頂有一根翹毛。

翹毛現在放在 `H.top + 0.045`（約 y=0.275），半徑高 0.040。殼頂在 lift 之下已經到 y≈0.31，翹毛整顆在殼裡面，所以 `look0` 頭頂是光的。

拿掉第二層瀏海殼。五團橢球貼在額上，下緣對齊 y=0.062，左右蓋過太陽穴：

```js
for (const x of [-0.112, -0.056, 0, 0.056, 0.112]) {
  const sy = x === 0 ? 0.022 : 0.026;
  ell(x, 0.062 + sy, H.frontZ(x, 0.09) + 0.012, x === 0 ? 0.032 : 0.040, sy, 0.018);
}
```

中間那團矮一點，額中留約 1 cm 的縫。外緣到 `|x|≈0.15`，和側髮接上。旁分、鮑伯、雙丸子、馬尾、長髮、側捲的單顆扁球瀏海都換成同一組，只改哪幾顆留著：旁分留 −X 側三顆再加現有的斜瀏海；鮑伯和長髮拿掉 x=0 那顆，留下中縫。

翹毛改到殼外面：中心 `(0.03, H.top + outer + 0.022, 0.03)`，半徑 `(0.016, 0.028, 0.014)`，`rotation.z = -0.6`。戴帽時仍收進帽子。

### 3. 袖子是肩上的氣球

`G.sleeve` 肩端半徑 0.086，上臂半徑才 0.050。直徑 17 cm 的一圈布浮在肩線上，`look0` 的白袖和 `creator.png` 舉起的藍袖都是兩顆球。手臂以下仍是一根管子。

袖子留在肩關節上，剖面改成 `(y, r)`：

```text
(0.04, 0.062) (0.00, 0.066) (-0.045, 0.058) (-0.07, 0.052) (-0.072, 0)
```

y=0.04 那一圈埋進軀幹。袖口加圓環，本地 y=−0.062、環半徑 0.054、管徑 0.008，`rotation.x = π/2`。

帽 T 的長袖用同一條，末端改成 `(-0.12, 0.050) (-0.122, 0)`，袖口放在 y=−0.112。背心繼續用裡層米白，連身裙的袖子繼續用裙子的顏色。

### 4. 手套和前臂是同一條管子

手套縮放 `(0.050, 0.043, 0.031)`，寬只比前臂直徑多 1.2 cm。拇指縮放 0.018，又偏到掌心裡面。120 px 時手是腕子末端的一顆球，設計稿的連指手套是橫向的一塊，拇指在內側看得到。

掌心改成縮放 `(0.058, 0.036, 0.024)`，中心 `(0, -0.040, 0.010)`。寬 11.6 cm、高 7.2 cm。

拇指縮放 `(0.020, 0.014, 0.014)`，中心 `(-s * 0.046, -0.024, 0.018)`，約三分之一埋進掌心。`s` 是這隻手的左右號，−s 讓拇指朝向身體中線。

腕口加一圈同色環：半徑 0.042、管徑 0.007，本地 y=−0.006。顏色維持膚色往 `#E07860` 混 20%，roughness 0.72。

### 5. 短褲收到膝蓋，靴子留在腳踝下面

短褲圓柱高 0.15、中心在髖本地 y=−0.07，下緣在世界 y=0.36，膝在 0.325，幾乎貼著膝蓋。靴子球心在世界 y=0.065、半徑高 0.048，靴頂在 y=0.113，腳踝樞紐卻在 y=0.165。小腿從膝到靴頂約 20 cm 全是半徑 0.05 的管子。`01-turnaround.png` 的靴口在小腿中段，短褲和靴子之間只留一截大腿。

短褲：圓柱高 0.10，髖本地中心 y=−0.025，下緣世界 y=0.43。褲口環放在髖本地 y=−0.075，環半徑 0.070、管徑 0.012。

靴子改掛在腳踝上，位置用世界高度來對（腳踝世界 y=0.165）：

- 鞋身：球縮放 `(0.056, 0.090, 0.082)`，世界中心 `(0, 0.130, 0.028)`。寬 0.112、高 0.180、長 0.164，頂在世界 y=0.220。
- 鞋底盒：`0.116 × 0.024 × 0.170`，世界中心 `(0, 0.018, 0.032)`，顏色是鞋色的 72%。
- 靴口環：半徑 0.064、管徑 0.014，世界 y=0.205，`rotation.x = π/2`，X 再乘 1.05。

小腿裸露從 y=0.220 到膝 0.325，約 10 cm。大腿從短褲下緣 0.43 到膝，約 10 cm。

### 6. 棒球帽是一顆穹頂，帽簷插進眼睛

`look4` 的冠用 `off = outer * 1.7 + 0.008`，再進 `headShell` 乘 lift，頭頂外偏約 0.16。`keep` 是 `y>0.07 && z<0.10`，殼往前包過額頭。帽簷是半徑 0.09 的半圓柱，中心 z 設成 `frontZ + off + 0.03`（約 0.27），繞 X 轉 −18° 之後掃過眼睛。四分之三視角那一塊黃髮被帽簷切成楔形，右眼只剩一半。

冠坐在髮殼外面，不要再乘 1.7，也不要再乘 lift：

- 外偏 `hairOuter + 0.018`，內偏 `hairOuter + 0.008`。旁分的 `hairOuter` 是 0.044，冠厚 1 cm。
- `keep`：`y > 0.10 && z < 0.02`。額髮和後頸留在外面。
- 帽簷改回盒子 `(0.18, 0.012, 0.09)`，中心 `(0, 0.10, 0.15)`，`rotation.x = -18°`。盒子的後緣在 z=0.105，塞進冠的前緣，不要再用 `frontZ + off`。

### 7. 毛帽把刺刺頭收成綠色頭盔

`look3` 同一條 `outer * 1.7` 再乘 lift，殼從 y=0.10 整圈包下來。底高過 y=0.15 的錐被 `if (hatted)` 拿掉，側面剩下的也被帽身擋住。設計稿的毛帽是頭頂一截，帽沿下面看得到瀏海和側髮。

- 外偏 `hairOuter + 0.016`，內偏 `hairOuter + 0.006`。刺刺頭 `hairOuter` 是 0.026。
- `keep`：`y > 0.13 && z < 0.06`。
- 帽沿圓環放在 y=0.125，管徑 0.022，環半徑用頭在這個高度的半寬再加 `hairOuter + 0.02`，約 0.20。不要用膨脹之後的 `off` 去加。
- 球頂維持半徑 0.045，中心 `(0, H.top + hairOuter + 0.04, -0.01)`，顏色 `#FFF9F2`。
- 錐只在底的 y > 0.18 時收進帽子。`(0, 0.8, 0.55)` 那根和兩側 `(±0.55, 0.85, 0.2)`、`(±0.9, 0.45, -0.1)` 都留在帽沿外。太陽穴絨球維持不動。

### 8. 雙馬尾、草帽丸子、花冠三個剪影不對

**雙馬尾。** 殼收到 y=−0.06，再加半徑 0.048、長 0.20 的膠囊，從正面看是兩片貼在頰上的厚髮。髮圈是一顆球，埋在這片裡面。`04-hairstyles.png` 的尾巴從耳後垂到鎖骨，粉圈在起點。

- 殼的 `keep` 改成 `y > 0.04 && z < 0.04 && !FACE_WIN && !NOTCH`。頰側不要留下殼。
- 瀏海用第 2 項的五團。
- 髮圈改圓環：半徑 0.026、管徑 0.007，中心 `(±0.16, 0.05, -0.05)`，顏色 `#F07AA0`，`rotation.x = 1.2`，再繞 Y 轉 `±0.6`，讓環從正面看得到。
- 尾巴：膠囊半徑 0.034、長 0.14，中心 `(±0.18, -0.05, -0.09)`，`rotation.z = ±12°`，`rotation.x = 0.25`。
- 尾端球半徑 0.032，中心 `(±0.21, -0.15, -0.10)`。

**草帽丸子。** 丸子在 `(±0.185, 0.11, -0.02)`、半徑 0.060，帽簷半徑 0.28 且上掀 12°，從正面整顆在簷的下面。`look1` 看不見丸子。

lift 拿掉之後，髮頂 `hairTop = H.top + outer`（雙丸子 outer 0.040，約 0.27）。帽子：

- `hat.position.y = hairTop - 0.06`，`rotation.x = -8°`。帽簷半徑 0.26、厚 0.012。冠半徑仍是 0.16。
- 丸子改到 `(±0.198, hairTop - 0.02, 0.01)`，半徑 0.056。中心比帽簷高 4 cm，比冠半徑多出約 4 cm，下緣坐在簷上。
- 髮圈跟著丸子：中心 `(±0.180, hairTop - 0.07, 0.00)`，顏色 `#F07AA0`。

**花冠。** 環在 y=0.12、管徑 0.022，花瓣球半徑 0.018。鮑伯頭的殼把這一圈吞進頭髮，`look5` 只剩一條綠線和幾粒點。

- 環放在 y=0.19，環半徑 0.19、管徑 0.012，顏色 `#6E9A62`。這個高度的髮殼半寬約 0.18，環貼在髮外，不埋進殼。
- 五朵只排前半圈。第 i 朵角度 `a = -1.0 + i * 0.5`，中心 `(sin(a) * 0.16, 0.205, H.frontZ(sin(a) * 0.12, 0.18) + outer + 0.02)`。
- 每朵五片花瓣，花瓣球半徑 0.024、厚 0.012，花心半徑 0.014。顏色沿用現在那五個 hex。

人耳在 `notch` 和光頭還是縮放 `(0.030, 0.055, 0.030)`。規格是 `(0.030, 0.055, 0.016)`，現在前後厚了一倍，旁分和刺刺頭的耳洞會頂出一塊餅。z 改回 0.016。

## 放進日式薄塗場景的材質

場景階位照 `island/ART-BIBLE.md`：0.00–0.42 影、0.42–0.72 中間、0.72–1.00 亮，平滑寬約 0.04。角色是圓的，55° 的主光下 N·L < 0.42 的面積比牆大得多，用場景那條會讓頭的下半整片進影子，五官被吃掉。角色用高一階的同一套三階，平滑半寬 0.045：

| 階 | N·L | 顏色 |
| --- | --- | --- |
| 影 | 0.00–0.30 | 下面的影色 |
| 中間 | 0.30–0.66 | 固有色 |
| 亮 | 0.66–1.00 | 固有色往 `#F6E2C4` 混 14% |

影不是固有色乘黑。

- 皮膚：固有色往 `#D7C2B8` 混 16%。聖經寫的往 `#C3C7D3` 混 28% 用在布上；蜜桃膚用 28% 冷灰，腮紅會變髒。
- 布：往 `#C3C7D3` 混 28%。珊瑚 `#F08A86`、`#E25B45` 只混 16%，點綴色才不會變成灰褐。
- 髮：明度 ≥ 0.25 的，往 `#C3C7D3` 混 22%。明度 < 0.25 的（墨棕、石板）不要混灰，影階改成固有色乘 0.75，否則深色頭髮沒有階。
- 鞋：往 `#9D836A` 混 24%。草帽：往 `#C4A574` 混 20%。

roughness／metalness，把現在頭髮的 0.55 和 metalness 0.02 拿掉，否則三階上面還會疊一層塑膠高光：

| 零件 | roughness | metalness |
| --- | --- | --- |
| 皮膚 | 0.88 | 0 |
| 臉片 | 0.95 | 0 |
| 頭髮 | 0.94 | 0 |
| 布 | 0.90 | 0 |
| 鞋 | 0.78 | 0 |
| 草帽 | 0.96 | 0 |

臉片繼續用 Standard 吃同一條 ramp。`emissiveMap` 仍只有五官，`emissiveIntensity` 從 0.4 降到 0.35，加在 ramp 之後，高光才不會被影階乘暗。臉片底色仍是那一檔膚色，外圈 6% 羽化留著。虹膜、瞳孔、高光都在貼圖裡，不要再做會反光的眼球網格。

頭髮加一圈 rim：顏色 `#F6E2C4`，強度 0.12。只在 `1 - N·V > 0.65` 且 `N·L < 0.50` 的像素上加，加進亮階的顏色，不要另打一盞燈。

描邊一支顏色 `#6A5A4E`。倒殼只包一層外輪廓：頭殼（不含臉片）、髮殼的外層、帽、軀幹、裙、袖、手套、鞋。沿法線膨 0.014 m（120 px 時約 1.2 px）。片段著色裡 `N·V > 0.28` 的丟掉，線才會在轉折處斷開，不會把每塊顏色框死。

這些不要進倒殼，也不要另描一圈：

- 臉片、眼鏡鏡片、鏡片上那道白高光
- 髮殼的內層（否則臉洞會有一圈線）
- 花瓣、花心、帽 T 的白繩、毛帽的白球頂、翹毛
- 耳內側的粉錐、粉球
- 瞳孔和高光（已經在臉貼圖裡）

草、水、雲、天空維持聖經的規定，不描邊。角色不要用不吃光的材質。珊瑚紅一個畫面仍只做一個焦點。

## 這一版可以留著

暖色膚色和髮色、衣服的大條紋、圓框眼鏡的尺寸、短脖子、三頭身、長裙收到 y=0.18、帽 T 的白繩和肩後帽兜、眨眼和五個表情的畫法，都對。臉打平的 z 漸入留著。改頭髮時不要把額收窄加回 0.24，也不要把 70% 的頭頂加厚加回去。
