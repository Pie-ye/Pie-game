# 派派鎮 像素素材規格（給 grok）

遊戲是星露谷物語風格的 2D 俯視像素遊戲，地形與作物用 Sprout Lands 素材包。新素材要和它**看起來是同一套**。

參考圖（請先看）：
- `refs/plants_ref.png`：Sprout Lands 的作物（小麥、甜菜）各生長階段，已放大 8 倍。**畫風、描邊、配色都照這個。**
- `refs/palette_ref.png`：Sprout Lands 官方調色盤（放大 24 倍）。顏色盡量只用這些。
- `refs/nature_ref.png`：同一套的樹、花、石頭。

硬性規定：
1. 每張圖只畫**一個**物件，**純洋紅色 #FF00FF 背景**（整片洋紅，不要漸層、不要陰影落在背景上、不要地面）。
2. 真正的像素畫：物件設計成 **16×16 像素**（特別註明的除外），每個像素畫成 **32×32 的方塊**，整張圖 512×512。不要抗鋸齒、不要模糊、不要漸層。
3. 柔和的暖色調、深紫褐色（約 #5d4150）一像素描邊，和參考圖一樣。俯視略帶正面角度。
4. 不要文字、不要邊框、不要格線。
5. 檔名照清單，存成 PNG 放在指定資料夾。
