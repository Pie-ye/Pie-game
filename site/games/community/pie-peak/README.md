# 菲比攀登 PEAK

單人 3D 攀岩生存遊戲，玩法參考 PEAK：**體力就是一切**。選菲比或弗洛洛，帶著坐在帽子上的瑞吉，從墜機的沙灘爬到火山口山頂等待救援。

## 核心規則

- **體力上限會被扣掉**：飢餓、受傷、中毒、寒冷、灼熱、睏倦與背包重量都會壓縮體力條。體力條右側的色塊就是被扣掉的部分。
- **徒手攀岩**：走向岩壁，按住抓牆鍵就能爬任何岩壁。靠 Space 蹬牆（耗體力）、吊在突出岩石下橫移、翻上平台。
- **昏倒**：體力上限歸零就昏倒。背包裡有復活星星會自動復活一次，否則回到最近的祭壇醒來，並丟失部分行李。
- **每日山**：地圖依日期（UTC）生成，網址加 `?seed=數字` 可指定種子。

## 四個區域，共 20 面岩壁

| 區域 | 特色攀爬物件與危險 |
| --- | --- |
| 海灘 | 砂岩、木梯、椰子樹（會掉椰子）、脆弱岩板、落石、尖刺陷阱 |
| 熱帶叢林 | 苔蘚岩壁、藤蔓、竹子、叢林巨樹、吊在突出岩下的橫移、捕蠅草、蜂窩、彈跳蘑菇、荊棘、黑暗山洞、雨天打滑 |
| 高山雪原 | 冰壁（要冰斧或冰爪）、冰柱墜落、發光水晶抓點、強風陣、寒冷累積、帳篷與營火避寒 |
| 火山口 | 熔岩壁（會灼傷）、間歇泉（把你噴上高處）、蒸氣孔、滾落熔岩石、落石堵塞（用炸藥炸開，後面有稀有補給） |

每區終點有祭壇：恢復體力、清除大部分負面狀態，並成為重生點。最後登上山頂信標，救援直升機就會抵達。

## 36 種道具

- **食物**：蘋果、野莓（可能中毒）、紅蘑菇（賭一把）、褐蘑菇、香蕉、椰子、航空小餅乾、能量飲料（爆發後會睡著）、彩虹棒棒糖、蜂蜜罐、烤魚串、巧克力餅乾
- **醫療**：急救箱、繃帶、解毒劑、萬能藥、暖暖包、冰敷袋、復活星星
- **攀登工具**：登山繩、岩釘、冰斧、冰爪、止滑手套、大背包、鏈條發射槍與備用鉤爪、滑翔傘、吹箭
- **野外裝備**：露營提燈、信號彈、指北針、望遠鏡、攜帶爐、睡袋、炸藥、誘餌起司
- **收集品**：童軍徽章（每枚結算 +500 分）

行李箱藏在平台與凸岩上，瑞吉會在附近有行李時吼叫；偶爾還會有補給箱空投。

## 3D 資產與製作流程

角色與場景全部是 Hunyuan3D 產出的 GLB，沒有手繪模型。

1. 參考圖由 Grok 生成（提示檔在 `tools/peak/grok-*.md`）。角色要求正面 A 字姿勢、雙臂雙腿與頭髮分開，方便綁骨架。
2. Colab（L4）跑 Hunyuan3D：`tools/peak/colab-gen.py`。
3. 骨架與蒙皮在 Colab 的 Blender（bpy）完成：`tools/peak/colab-rig.py` 搭配 `rig_profiles.py`。菲比與弗洛洛有 22 根骨骼，包含肩、肘、手腕、手指、髖、膝、踝；瑞吉有 13 根。
4. 遊戲內以雙骨 IK 驅動攀爬：左右手、左右腳交替抓住岩壁錨點（`src/rig.js`）。
5. 貼圖與圖示由 `tools/peak/process_assets.py` 處理，GLB 以 `tools/peak/optimize-glb.py` 壓縮貼圖。

菲比與弗洛洛是鳴潮的角色，這是粉絲作品，角色著作權屬於原權利人。

## 開發

- 模擬層（`src/game.js`、`player.js`、`worldgen.js`、`hazards.js`、`status.js`）不依賴 three.js，可以直接用 node 測試：`node --test tests/pie-peak.test.mjs`。
- 使用的 three.js r186 與 GLTFLoader 放在 `vendor/`，不需外部網路。
- 全部音效由 WebAudio 合成。
