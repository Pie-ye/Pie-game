# 室內資產來源

- [Kenney Mini Arcade](https://kenney.nl/assets/mini-arcade), version 1.0 (2024-07-03).
- Authors: Kenney, Fleur Keijsers, Guus Vermeulen.
- License: CC0 1.0. Original text: [LICENSE.txt](kenney-mini-arcade/LICENSE.txt).
- Download mirror: https://opengameart.org/content/mini-arcade
- Archive: https://opengameart.org/sites/default/files/kenney_mini-arcade.zip

The GLB files and their shared `Textures/colormap.png` are original pack files. Runtime code scales and arranges imported
architecture and cabinets, shares repeated meshes, tints architecture materials
and supplies lights/collision. It does not generate the cabinet/room geometry.

`arcade-homepage.webp` is a reference copy of this project's existing
`site/shell/city/assets/arcade.webp`; it is not part of the Kenney CC0 pack.
The room palette follows that reference (violet, cyan, pink).
