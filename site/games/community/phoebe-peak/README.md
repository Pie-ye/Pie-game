# 菲比啾比攀登（V2 · 多路線）

單人 3D 攀岩生存遊戲，玩法參考 PEAK：**體力條就是整個遊戲**。用菲比啾比爬上六個區域、約 550 公尺的山，沿途自己選路線、自己造路，並躲開瑞吉與升起的濃霧。登頂就通關，沒有分數，並解鎖更高難度。

## 路線不是一條線

山是一座九段的方形螺旋。每一段是並排的**三條路線**，段與段之間是平坦的營地，三條路線在營地重新匯合：

| 路線 | 特色 |
| --- | --- |
| 緩徑 | 階梯平緩、不會有平地，長椅可歇、危險少、物資少，但繞遠路會餓 |
| 直壁 | 高壁與平地交錯，很吃體力；有垂藤與固定岩釘 |
| 險徑 | 補給箱、水晶最多，荊棘、冷熱、落石、瑞吉也最多 |

三條路線是真的並排的岩柱，所以可以在路線之間橫移：兩條路線高度相同的地方可以直接走過去（每段至少一處），高度差小時可以攀過去。每個營地前有路標與三色旗（綠＝緩徑、藍＝直壁、紅＝險徑）。**每天的山都不同**：整座山會旋轉或鏡像（八種擺法）、三條路線的位置重新洗牌、危害與物資重新分布。按 **M** 看路線圖。

## 核心規則

- **體力上限會被扣掉**：飢餓、受傷、中毒、寒冷、燥熱、背包重量。體力條右側的色塊就是被扣掉的部分。
- **額外體力**（金色）：穀物棒、蜂巢蜜、水晶、烤過的食物會加，優先消耗，不會自己恢復。
- **昏迷**：體力上限被扣到幾乎為零、摔落超過 24 公尺、掉進海裡，會昏迷並在最近啟動的祭壇醒來。第 2 階起昏迷會掉部分道具。
- **食物是賭博**：航空零食與椰子安全；野莓與蘑菇有機率中毒，但**拿到營火上烤熟就安全**（E）；能量飲料 25 秒快速攀爬，之後昏睡 7 秒。
- **濃霧**：登山客以上，8 分鐘後濃霧從山腳升起，追上你會持續失去體力；霧升過的營地不能再當存檔點，所有營地都被淹沒就失敗。新手營沒有霧。
- **瑞吉**：守在岩柱上，險徑最多；爬得比步調快太多會被攔。吹箭讓他睡著。
- **難度（Ascent）**：共 8 階，登頂後解鎖下一階，每階保留前面的所有規則並加上一條：新手營（攀爬 −30%、無濃霧）、登山客、摔傷加倍、飢餓 +60%、道具變重、寒夜、攀爬 +40%、瑞吉成群。

## 道具（30 種）

- **吃的與藥**：航空零食、椰子、穀物棒、蜂巢蜜（從蜂巢取，會被叮）、冬莓、野莓、蘑菇、能量飲料、繃帶、急救箱、解毒劑、熱茶、冰敷袋、蘆薈、萬靈丹。
- **造路的工具**：繩索捲（在平台邊緣垂繩）、岩釘（附近休息，體力歸零時救你）、鏈條發射器（射向上方岩壁拉自己上去）、**魔豆**（在高牆前種出 12 公尺藤蔓）、**棚架菇**（在牆上長出可站立 40 秒的平台）、**彈跳菇**（踩上去彈高約 5 公尺）、**陽傘**（拿在手上，空中緩降且不摔傷）、**氣球**（20 秒低重力）。
- **其他**：吹箭、提燈、**指南針**（畫面指出下一個營地）、**路標旗**（單次自訂重生點）、**登山背包**（+2 格，最多 6 格）。

## 操作

| 動作 | 按鍵 |
| --- | --- |
| 移動／攀爬方向 | WASD、方向鍵 |
| 跳躍／在牆上蹬躍（20 體力，一次上升 2.6 公尺） | Space |
| 衝刺 | Shift |
| 走向岩壁 | 自動抓牆；平台邊緣或空中可按住 **C** 抓住下方岩壁 |
| 放手／往後跳 | C（牆上）、Space＋S |
| 互動（撿東西、開箱、祭壇、水晶、蜂巢、營火烤食物） | E |
| 使用物品／丟棄／切換 | F 或左鍵／G／1–6、Q、Z |
| 路線圖 | M |
| 視角 | 直接移動滑鼠（點「開始攀登」後自動鎖定滑鼠，Esc 暫停並釋放）、滾輪縮放；也可右鍵拖曳 |

觸控裝置有搖桿與按鈕。

## 危害與攀爬物件

荊棘、濕滑苔蘚與冰面、灼熱岩壁、會碎裂的平台、間歇泉、火焰噴口、孢子雲（睡著後有短暫免疫）、蜂巢、落石、強風、垂藤與繩索、牆面休息平台、營火、祭壇、補給箱、體力水晶。

## 角色、美術與骨架

- 菲比啾比：用 `phoebe_chibi_anima` LoRA（Anima 底模）出 Q 版正面 A 字站姿圖，Colab 的 Hunyuan3D-2 轉成 3D，`tools/phoebe-peak/build-rig.py` 依顏色與位置分出髮辮、手臂、身體，算出 21 根骨頭與蒙皮權重。`src/pose.js` 以 FK 做走跑、雙骨 IK 做攀爬。`rig-preview.html` 可檢視各種動作。
- 場景道具、營地小屋、道具模型與天空：用 `Mountain_village_fantasy` LoRA（SDXL）出圖，再轉 3D。
- 岩壁與平台：不是重複貼同一塊模型，而是依世界座標取樣 LoRA 貼圖，並在頂點著色器用噪音做起伏，所以不會有接縫與重複。
- 瑞吉：沿用搬蛋大作戰的四種攻擊姿勢模型。

## 結構與驗證

- `src/world.js`：九段、每段三條路線、營地、危害、道具的生成（依日期種子）。
- `src/game.js`、`physics.js`、`reggie.js`：邏輯與碰撞，不依賴繪圖。
- `src/terrain.js`、`scene.js`、`hud.js`：繪圖與介面（含路線圖與指南針）。
- `src/bot.js`：自動爬山機器人，可指定每一段走哪種路線，供測試與平衡檢查。
- 測試：`node --test tests/phoebe-peak.test.mjs tests/phoebe-peak-models.test.mjs`；瀏覽器測試見 `tests/phoebe-peak-browser.cjs`。
- 開發參數：`?seed=<日數>&ascent=<0-7>&autostart=1`。

美術流程見 `tools/phoebe-peak/ART-NOTES.md`。使用專案既有 `../pie-phoebe/vendor/three.module.js`。角色同人造型權利屬於各自權利人。
