# 菲比啾比攀登（V1.2）

單人 3D 攀岩生存遊戲，玩法參考 PEAK：**體力條就是整個遊戲**。用菲比啾比爬上六個區域、共 512 公尺的山脈，路上會被瑞吉攻擊。登頂就通關，沒有分數，並解鎖更高難度。

## 核心規則

- **體力上限會被扣掉**：飢餓、受傷、中毒、寒冷、燥熱、背包重量。體力條右側的色塊就是被扣掉的部分。
- **昏迷**：體力上限被扣到幾乎為零、摔落超過 24 公尺、掉進海裡，會昏迷並在最近啟動的祭壇醒來（單人版沒有隊友救援）。第 2 階起，昏迷會掉部分道具。
- **食物是賭博**：航空零食與椰子安全；野莓與蘑菇有機率中毒；能量飲料 25 秒快速攀爬，之後昏睡 7 秒（掛在牆上會直接滑落）。
- **工具把弱者救回來**：繩索捲（在平台邊緣垂繩）、岩釘（釘在牆上，附近休息不耗體力，體力歸零時救你一次）、鏈條發射器（射向上方岩壁把自己拉上去）、吹箭（讓瑞吉睡 12 秒）、提燈（幽暗區域視野變遠）。
- **六個區域**：海灘（固定第一關）、熱帶、高山、火山口、熔爐、城塞。高山與火山口每天可能變成「幽暗」版本（昏暗、孢子會讓人昏睡）。地圖由日期決定，每 24 小時更換。
- **懲罰太早衝**：爬得比步調（每區 0.55 公尺／秒加 38 公尺餘裕）快太多，瑞吉會出現在上方平台攔你。
- **難度（Ascent）**：共 5 階，登頂後解鎖下一階；提高飢餓速度、中毒機率、危害密度、瑞吉數量與攻擊強度，降低補給。

## 操作

| 動作 | 按鍵 |
| --- | --- |
| 移動／攀爬方向 | WASD、方向鍵 |
| 跳躍／在牆上蹬躍（20 體力，一次上升 2.6 公尺） | Space |
| 衝刺 | Shift |
| 走向岩壁 | 自動抓牆；平台邊緣或空中可按住 **C** 抓住下方岩壁 |
| 放手／往後跳 | C（牆上）、Space＋S |
| 互動（撿東西、開箱、祭壇、水晶） | E |
| 使用物品／丟棄／切換 | F 或左鍵／G／1–4、Q、Z |
| 視角 | 滑鼠右鍵拖曳、滾輪 |

觸控裝置有搖桿與按鈕。

## 危害與攀爬物件

荊棘（受傷並被彈開）、濕滑苔蘚與冰面（下滑、耗更多體力，可用蹬躍通過）、灼熱岩壁、會碎裂的平台、間歇泉、火焰噴口、孢子雲、落石（地面會先出現紅圈）、強風（耗體力、把你吹離牆面）、垂藤與繩索、牆面休息平台、營火、祭壇、補給箱、體力水晶。

## 角色與骨架

菲比的網格由 Colab 的 Hunyuan3D-2 產出；`tools/phoebe-peak/build-rig.py` 離線計算 21 根骨頭與蒙皮權重（距離加髮絲／身體分割，再做拉普拉斯與空間平滑，讓分離的臉、髮、帽一起變形）。`src/pose.js` 以 FK 做走跑，以雙骨 IK 做攀爬時雙手貼岩、拉繩、釘在岩釘上、翻上平台與吃東西（手到嘴）。`rig-preview.html` 可檢視各種動作。瑞吉用四種攻擊姿勢各一個模型（吼叫、拍地、衝撞、甩身）切換，並依判定範圍做動作。

## 結構與驗證

- `src/world.js`：七乘七格圓錐螺旋塔，每格一個岩柱＝一段攀爬，依日期種子生成。
- `src/game.js`、`physics.js`、`reggie.js`：邏輯與碰撞，不依賴繪圖。
- `src/scene.js`：以 GLB 模組實例化出岩壁、平台、道具與天空；`pose.js`、`rig.js` 角色動畫。
- `src/bot.js`：自動爬山機器人，供測試與平衡檢查。
- 測試：`node --test tests/phoebe-peak.test.mjs tests/phoebe-peak-models.test.mjs`。
- 開發參數：`?seed=<日數>&ascent=<0-4>&autostart=1`。

美術流程見 `tools/phoebe-peak/ART-NOTES.md`。使用專案既有 `../pie-phoebe/vendor/three.module.js`。角色同人造型權利屬於各自權利人。
