# 小島樂園（PIE ISLAND）

陽光小島上的多人散步遊戲。先捏一個自己，登島後用第三人稱到處逛，同一時間在島上的玩家都會出現在同一個場景裡，可以揮手、比愛心打招呼。

## 操作

- **WASD／方向鍵**：走路（以鏡頭方向為準）；**Shift**：跑；**Space**：跳。
- **滑鼠拖曳**：轉鏡頭；**Q／E**：左右轉鏡頭；**滾輪**：拉近拉遠。
- **1–5**：表情（揮手、開心、喜歡、驚訝、疑問）。其他玩家會看到頭上的泡泡與動作。
- **C**：捏臉；**Esc**：選單；**M** 音效、**N** 音樂、**H** 隱藏介面。
- 手機：左半邊拖曳走路（推到底會跑）、右半邊拖曳轉鏡頭，右下有跳、跑按鈕。

## 捏臉

參考動物森友會的 Q 版比例：大頭、短身、圓手圓腳，臉是貼在頭部正面的手繪風五官。

| 分頁 | 項目 |
| --- | --- |
| 臉 | 膚色 8、眼睛 8、眼珠顏色 6、眉毛 5、鼻子 4、嘴巴 7、腮紅／雀斑 4 |
| 髮型 | 髮型 9、髮色 12、耳朵 4（人耳／貓耳／熊耳／兔耳） |
| 服裝 | 上衣 4（T 恤／連身裙／帽 T／背心）、14 色、花紋 5、下身 3、下身顏色、鞋子顏色 |
| 配件 | 帽子 6（草帽、毛帽、棒球帽、花冠、小葉子）、眼鏡 3 |

外觀存在瀏覽器的 `localStorage`，第一次進來會先開捏臉畫面。角色會自己眨眼，做表情時會換成開心臉。

## 小島

島中央是噴水池廣場（攤位、長椅、路燈），步道通往：

- 南邊沙灘的小碼頭（可以走到盡頭，旁邊停著小船，遠方有帆船）
- 東西兩側的四間小屋（門都朝廣場，旁邊有信箱）
- 北邊的瞭望高台（只能從坡道上去）、東北的蓮花池、北邊的小農田
- 東南海邊的營地（帳篷、營火、獨木舟）

沙灘可以涉水走進淺灘，深水與池塘走不進去。擺設用固定亂數種子產生，每個玩家看到的島都一樣。

## 多人

登入後自動加入公開房間「小島樂園」（每間最多 16 人，滿了會開新的一間；兩人同時開房會自動合併）。訊息格式：

| 訊息 | 內容 |
| --- | --- |
| `{k:'s', s:[x,y,z,yaw]}` | 位置，約每 0.1 秒檢查一次，有變才送，站著不動時每秒一次心跳 |
| `{k:'l', l:[…]}` | 外觀（18 個整數索引），進房、有人加入、改完臉時送 |
| `{k:'e', e:'wave'}` | 表情 |
| `{k:'q'}` | 密語：請對方把外觀與位置再送一次（收到陌生人的位置時用） |

收到的外觀一律經過 `sanitize()` 檢查範圍，亂傳的值會變成預設值。未登入或網址帶 `?solo=1` 時是單機模式。

## 素材

場景模型全部是 Kenney 的 CC0 素材包（Nature Kit、Pirate Kit、Fantasy Town Kit），清單與授權見 `assets/CREDITS.md`。地形、海水、天空、小屋屋頂、角色與音樂是程式產生的，沒有外部資源。整款遊戲約 1.6 MB。

## 網址參數

`solo=1` 單機、`shadows=0` 關陰影、`pr=1` 指定像素比、`fps=30` 幀率上限（0 不限）、`autoq=0` 關閉自動降畫質。

## 程式

```
src/main.js         渲染、輸入、鏡頭、介面、主迴圈
src/layout.js       地形高度、步道、擺設、碰撞與移動（純函式，node 可測）
src/island.js       地形網格、海水著色器、天空與雲、模型實例化、小屋
src/look.js         捏臉資料：選項、預設、隨機、驗證、存檔
src/face.js         五官繪製（貼圖與選單小圖示共用）
src/character.js    Q 版角色模型、動作、表情泡泡
src/creator.js      捏臉畫面
src/avatars.js      其他玩家（內插、名牌）
src/multiplayer.js  連線、房間、訊息
src/audio.js        程式合成的海浪、鳥叫、音樂、音效
```

測試：`node --test tests/pie-island.test.mjs`；瀏覽器與多人測試見 `tools/pie-island/`。
