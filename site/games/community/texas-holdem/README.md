# 德州撲克

二到六人牌桌。房主的瀏覽器跑 `engine.js`（發牌、盲注、加注規則、邊池、攤牌），公開狀態用 `setState('table')` 同步，底牌用 `send(data, to)` 私訊。

- 虛擬籌碼：起始 1,000、盲注 10／20，沒籌碼自動補滿。多人遊戲依平台規定不能用金幣。
- 每次行動 30 秒，逾時自動過牌或棄牌。每手結束 6 秒後自動開下一手。
- 玩家進出即時反映在牌桌上；房主離開時由下一位房主用公開狀態接手，進行中的那手作廢並退回已投入的籌碼。
- 房主看得到引擎裡所有底牌，所以這是朋友之間的玩法，不防作弊。
- 規則引擎測試：`node --test tests/holdem-engine.test.mjs`。
- 貼圖來自 `tools/casino-art`（gwentCB01 LoRA）。
