# 菲比啾比星光亂鬥 v1.3

three.js 做的類吸血鬼倖存者（俯視、自動攻擊、撿小魚升級）。主角是《鳴潮》的菲比（網路暱稱「菲比啾比」），寵物是海獅「瑞吉」。同人作品，角色屬於各自的權利人。

目標：撐過 12 分鐘，並擊敗第 3、6、9 分鐘出現的三位頭目，之後可繼續無盡模式。時間到但頭目仍存活時需繼續戰鬥。最佳紀錄存在 `localStorage` 的 `pg-phoebe-best`，音效開關存在 `pg-phoebe-mute`。

## v1.3：技能、特效與地圖更新

本次重點是讓每個技能有清楚用途。所有角色技能仍有 8 級、最多帶 5 種。`src/skills.js` 是施法與選卡數字的共同來源；圖鑑列 Lv1 基礎值，升級卡列升級前後值，暫停／結算可看傷害貢獻（光噪另列，排除溢出傷害）。

| 技能 | 用途與效果 |
| --- | --- |
| 聖光三連 | 追蹤普攻，第三輪 ×1.5；站進鏡環再 +35%。最多 3 發，穿透後保留 65% 傷害 |
| 鏡之環 | 固定於敵人位置的鏡陣，持續 5 秒；聚怪、短暫停滯、邊緣攔彈，普攻命中環內敵人時追加折射 |
| 重擊・星輝 | 貫穿光束與落地星柱；光噪每層 +4%。Lv6 追加一束 55% 傷害光束 |
| 默禱領域 | 近身持續傷害、疊層、減速 |
| 告解迴響 | 擴散光環，擊退、疊層、清除彈幕；每波對同一敵人只命中一次 |
| 啟明之鏡 | 鏡片先凝聚再碎裂，大範圍爆發與清彈 |
| 折射聖輝 | 原連鎖雷光改為衍射光線，在不同敵人之間折射 |
| 鏡光停滯 | 原冰晶祈願改為鏡晶停滯，減速 60%、易傷 20%；頭目只減速 20%，不暈眩 |
| 巡星光痕 | 移動留下光印，追兵踏入受傷；重疊光印不重複計傷 |

五組連攜皆為雙技能 Lv3：聖輝折射（額外 2 目標）、停滯星輝（對減速敵人重擊 +40%）、踏浪巡星（瑞吉滑行留 1.5 倍光痕）、鏡映星輝（召鏡追加 60% 重擊基礎傷害的範圍星柱）、默禱迴響（迴響對至少 4 層光噪的敵人 +50%）。

重新分配低級傷害、冷卻與高級多重命中倍率。角色傷害另隨玩家等級每級 +2.5%、最高 +90%（再與被動、形態相乘），減輕後期敵人血量成長造成的落差。降低扇形水母射頻：2.4 → 4.8 秒，初次射擊隨機延遲 2.4～4.8 秒；普通射手維持 2.4 秒。

特效採金色赦罪／青色告解、浮空鏡片、八角法陣、縱向星柱與碎鏡光片。紅色頭目危險預警使用獨立上層，不與技能光效共用容量。

地圖「黎那汐塔・啟明廣場」是鳴潮黎那汐塔海岸建築意象的原創同人地圖，不是官方地圖擷取。固定 58×58 地面，玩家限制於半徑 22 的廣場；一般波次與包圍波出生距玩家至少 8（死亡分裂除外），掉落物會留在可到達的陸地。取代無限移動的網格背景。

## v1.2 更新紀錄（技能已由 v1.3 重製）

- 四種新敵人：尖嘯衝鋒獸（75 秒）、散音水母（145 秒）、落雷石偶（225 秒）、裂音母體（300 秒）。分別使用鎖定方向衝鋒、扇形射擊、延遲地面轟炸、死亡分裂。新敵人沿用既有貼圖，以顏色及尺寸區別。
- 三位頭目：破陣者、織音者、終曲指揮，分別從衝鋒、缺口彈幕、落雷開始輪替；終曲指揮追加交叉落雷。低於 45% 生命時縮短招式間隔。衝鋒有 1.15 秒紅線預警，彈幕有 1.2 秒青色缺口提示，落雷至少預警 1.1 秒；衝刺後有 1 秒停頓。
- 三種新角色技能：連鎖雷光、冰晶祈願、巡星光痕，各有 8 級。維持最多 5 種角色技能，搭配取捨依然重要。
- 三組連攜（兩項各 Lv3 自動啟動）：星輝＋雷光多跳 2 個目標；聖祷＋冰晶對減速目標的光束傷害 +60%；光痕＋瑞吉滑行讓滑行留下 1.5 倍傷害光痕。升級卡顯示門檻與目前等級，HUD 顯示已啟動連攜。
- 菲比叫聲只在開場、祈願、擊敗頭目與勝利時觸發，所有來源共用至少 12 秒間隔，最多一段同時播放。

## 角色設計依據

菲比（鳴潮）是衍射屬性共鳴者。遊戲裡取用她的幾個招牌，名稱與數值是本遊戲的改編，不是原作數值：

- **光噪效應**：所有技能都會在敵人身上疊層，層數越高，每秒的衍射傷害與後續傷害加成越高。
- **祈願**：每秒 +5，滿 120 後二選一，發動後 15 秒內不能再切換。
  - **赦罪**（輸出）：攻擊 +35%、普攻更快，對光噪目標重擊額外 +40%，啟明之鏡 +50%；發動時立即造成基礎 90 的範圍傷害。
  - **告解**（輔助）：所有光噪疊 3 倍、直接傷害 +20%、光噪持續傷害 ×1.6、默禱領域變大、持續回血、瑞吉攻擊 +30%；發動時立即造成基礎 40 的範圍傷害並疊層。
- 光噪上限 12 層，每 0.9 秒傷害 `(3 + 層數 × 2.2) × 角色攻擊倍率`，之後減 1 層；告解再乘 1.6。

## 瑞吉設計依據

網路上的海獅瑞吉：愛吃小魚、胖嘟嘟、愛張大嘴巴大叫。

- 預設技能「張嘴吼」：張大嘴巴大叫，震退並暈眩周圍敵人。
- 「肚皮滑行」：趴下衝撞敵群。
- 「貪吃」：瑞吉會自己衝去吃小魚（也會給你經驗）。吃滿後「吃飽」：變胖、傷害 ×1.5、技能冷卻縮短，並打一個大嗝。

## 美術與授權

- 角色、敵人、道具、星光、鏡環、地板圖由 Grok 圖像生成（`assets/`，已去背縮圖）。生成提示與後處理腳本在上層 repo 的 `tools/pie-phoebe/`。
- 光暈、環、光束、陰影等純漸層貼圖由 `src/fxtex.js` 在執行時畫出。
- v1.3 地圖由內建 imagegen 生成，檔案為 `assets/rinascita-plaza.png`；完整提示詞在 [MAP-ART.md](./MAP-ART.md)。鏡片、法陣、光柱是 `src/fxtex.js` 產生的透明幾何特效貼圖。
- 音效：兩種叫聲都是真實取樣（`assets/audio/`），其餘音效由 WebAudio 即時合成。
  - 菲比：`phoebe_1..4.mp3`，「菲比啾比」四個音節。一般施法不播放叫聲，僅在開場、祈願、擊敗頭目與勝利時嘗試播放；共用 12 秒間隔。
  - 瑞吉：`reggie_1..4.mp3`，各是連續三聲「嗷、嗷、嗷」。張嘴吼起手和肚皮滑行出發時各叫一次。
  - 菲比最多同時播放一段叫聲，瑞吉最多兩段。
- 版權：兩種叫聲都沒有取得授權。菲比叫聲取自庫洛遊戲《鳴潮》團子的語音，瑞吉叫聲取自 YouTube 上的海獅影片，都是別人上傳的公開影片切片。公開上線前請自行評估；不想用就清空 `assets/audio/manifest.json` 對應的陣列，會退回合成音。

## 程式結構

| 檔案 | 內容 |
| --- | --- |
| `src/main.js` | 啟動、鍵盤／觸控輸入、主迴圈、SDK |
| `src/game.js` | 世界狀態、武器、瑞吉、敵人、渲染 |
| `src/data.js` | 技能／被動／敵人設定與升級文字 |
| `src/skills.js` | 技能數值、數字說明、廣場邊界 |
| `src/gfx.js` | InstancedMesh 看板與地面貼花 |
| `src/ui.js`、`style.css` | HUD 與各畫面 |
| `src/audio.js` | 合成音效 |

測試用：網址加 `?bot=1` 會由機器人自動遊玩；`window.__pie` 可取得遊戲物件。

規則回歸測試：`node tests/pie-phoebe.test.mjs`；音效冷卻測試：`node tests/pie-phoebe-audio.test.mjs`。瀏覽器測試：先以 `python3 -m http.server 18766 --bind 127.0.0.1 --directory site` 開啟本機服務，再執行 `node tests/pie-phoebe-browser.cjs`（可用 `PLAYWRIGHT_MODULE` 指定 Playwright 安裝位置、`PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定瀏覽器）。

規則測試會輸出每個技能 Lv1／4／8 的 30 秒六目標傷害基準。這是固定靶群、無被動、無形態、排除光噪持續傷害的比較，不是實戰 DPS 或通關率承諾；控場／防守技能還有清彈、易傷與走位價值。瀏覽器驗證含 60 秒後期戰鬥模擬、實際貼圖載入、特效實例、手機拖曳與選卡。
