# 菲比啾比星光亂鬥 v1.4

three.js 做的類吸血鬼倖存者（俯視、自動攻擊、撿小魚升級）。可選角色是《鳴潮》的菲比（網路暱稱「菲比啾比」）與弗洛洛，寵物是海獅「瑞吉」。同人作品，角色屬於各自的權利人。

目標：撐過 12 分鐘，並擊敗第 3、6、9 分鐘出現的三位主線頭目，之後可繼續無盡模式。期間還會出現三位精英頭目（不影響勝利，擊敗會掉寶箱）。時間到但頭目仍存活時需繼續戰鬥。最佳紀錄存在 `localStorage` 的 `pg-phoebe-best`，音效開關 `pg-phoebe-mute`，角色 `pg-phoebe-char`，特效亮度 `pg-phoebe-fx`。

## v1.4 更新

### 1. 新角色：弗洛洛

標題畫面可選角色（點選或左右鍵），弗洛洛的圖來自專案圖庫。技能參考《鳴潮》弗洛洛的機制（彼岸花、轉生、不穩定音符、緋紅終章、赫卡忒），名稱與數值是倖存玩法的改編，不是原作倍率。

| 技能 | 用途與效果 |
| --- | --- |
| 彼岸斬 | 起始技能。朝最近的敵人揮出 120 度弧斬，疊 1 層湮滅侵蝕，每次命中產生 1 個不穩定音符並回少量生命。Lv4 追加反手斬，Lv7 追加第三斬 |
| 轉生之夢 | 在敵群綻放彼岸花：凝滯、減速、疊 2 層侵蝕、產生 2 個音符 |
| 緋紅終章 | 音符累積到 6 個（Lv6 起 5 個）時自動施放，把周圍敵人牽引到中心後重擊 |
| 彼岸花環 | 數片花瓣繞身旋轉，持續切割靠近的敵人 |
| 樂章（Q） | 樂章條充滿後按 Q 召喚赫卡忒 15 秒：傷害 +25%、音符加倍，赫卡忒會自己揮鐮（每三下一次全周大斬） |

連攜（雙方 Lv2）：**夢中斬**（彼岸斬砍中被凝滯的敵人 +60%）、**花海終章**（緋紅終章引爆 3 層以上侵蝕，+70% 並消耗 3 層）。弗洛洛生命 120，近身高輸出。侵蝕沿用光噪的疊層與持續傷害規則。

### 2. 連攜與平衡

- 連攜門檻由雙方 Lv3 降到 Lv2。啟動時有橫幅與提示音，每次觸發會在敵人身上顯示文字與光圈。HUD 會顯示進度中的連攜（虛線）。
- 升級卡：對方技能已持有、自己還沒到 Lv2 的卡，被抽中的機率 ×2.5，卡面標示「★連攜」。
- 暫停與結算畫面會另列「連攜額外傷害」。
- 技能平衡由 `tools/pie-phoebe/balance.mjs` 量測，`calibrate.mjs` 迭代調整 `src/balance.js` 的各等級傷害倍率。九項菲比技能、四項弗洛洛技能在所有等級的相對強度都落在 100 附近（量測結果見 `tools/pie-phoebe/balance-v1.4-*.md`）。弗洛洛的基準對齊菲比，兩角色整體強度相當。

### 3. 瑞吉

- 移除「貪吃」：不再吃魚、沒有吃飽狀態與嗝。小魚由玩家自己撿。
- 張嘴吼降傷（保留暈眩與擊退的控場用途）。
- 肚皮滑行改為「環繞滑行」：以玩家為圓心繞圈滑行並撞擊沿途敵人，結束後回到角色身旁。Lv8 繞兩圈。踏浪巡星連攜沿繞圈路徑留下光痕。
- 瑞吉的傷害占整體約 3% 到 11%（v1.3 約 7% 到 20%）。

### 4. 六隻頭目

每隻都有專屬的圖和機制。畫面同時可有多條血條；破防時血條外框變金色，護罩時變青色。

| 頭目 | 出場 | 機制 |
| --- | --- | --- |
| 潮鳴蟹將（精英） | 100 秒 | 護盾吸收傷害，打破後 3.5 秒破綻（+50%），14 秒後重組。蟹鉗橫掃（扇形預警）與泡沫齊射 |
| **破陣者**（主線） | 180 秒 | 衝鋒時讓他撞到場地邊牆會「撞牆破防」3.5 秒（+60%）。另有震地、狂暴時加速並追加震地，血量低時召喚雜兵 |
| 迴光燈塔（精英） | 280 秒 | 旋轉光束（半血起雙光束），光束結束後「熄燈」3 秒破綻（+50%）。定時射出追蹤彈 |
| **織音者**（主線） | 360 秒 | 開場與半血時各召喚 3 根共鳴柱。柱存活時織音者只吃 15% 傷害並噴旋轉音符彈幕，拖太久加環形彈幕。擊破全部共鳴柱後 4 秒破綻（+50%） |
| 噪潮母巢（精英） | 460 秒 | 定時產生噪卵，6 秒內沒擊破就孵出衝鋒獸。半血起召喚蝠群 |
| **終曲指揮**（主線） | 540 秒 | 三樂章。第一樂章：對向旋轉光束＋落雷。第二樂章：光束加速、召喚樂手、十字落雷。終樂章：六個扇區輪替只留兩個安全，加慢速光束 |

預警規則：紅線、紅圈、紅色扇形與光束都是預警，離開就不會受傷；預警期間不傷人。無盡模式每 150 秒依序輪替六隻，之後每輪多一隻同時出場。

### 5. 特效變淡

技能特效層的基準透明度約為 v1.3 的六成，並限制同時存在的光環數量。右上角 ✨ 按鈕（或按 F）可切換低、中、高三檔亮度，預設為中。紅色預警層不受影響。

## 菲比的技能（v1.3 起）

所有角色技能都有 8 級，最多帶 5 種。`src/skills.js` 是施法與選卡數字的共同來源。

| 技能 | 用途與效果 |
| --- | --- |
| 聖光三連 | 追蹤普攻，第三輪 ×1.5；站進鏡環再 +35%。最多 3 發，穿透後保留 65% 傷害 |
| 鏡之環 | 固定於敵人位置的鏡陣，持續 5 秒；聚怪、短暫停滯、邊緣攔彈，普攻命中環內敵人時追加折射 |
| 重擊・星輝 | 貫穿光束與落地星柱；光噪每層 +4%。Lv6 追加一束 55% 傷害光束 |
| 默禱領域 | 近身持續傷害、疊層、減速 |
| 告解迴響 | 擴散光環，擊退、疊層、清除彈幕；每波對同一敵人只命中一次 |
| 啟明之鏡 | 鏡片先凝聚再碎裂，大範圍爆發與清彈 |
| 折射聖輝 | 衍射光線在不同敵人之間折射 |
| 鏡光停滯 | 鏡晶停滯，減速 60%、易傷 20%；頭目只減速 20%，不暈眩 |
| 巡星光痕 | 移動留下光印，追兵踏入受傷；重疊光印不重複計傷 |

五組連攜（雙方 Lv2）：**聖輝折射**（額外跳 2 個目標且 +25%）、**停滯星輝**（重擊對減速敵人 +60%，顯示「碎！」）、**踏浪巡星**（瑞吉繞圈留下 2 倍光痕）、**鏡映星輝**（召鏡時落下 100% 重擊的星柱）、**默禱迴響**（迴響引爆 3 層以上光噪：+80%，消耗 3 層）。

角色傷害另隨玩家等級每級 +2.5%、最高 +90%。扇形水母射頻 4.8 秒，普通射手 2.4 秒。

地圖「黎那汐塔・啟明廣場」是鳴潮黎那汐塔海岸建築意象的原創同人地圖，不是官方地圖擷取。固定 58×58 地面，玩家限制於半徑 22 的廣場。

## 角色設計依據

菲比（鳴潮）是衍射屬性共鳴者，取用她的幾個招牌，名稱與數值是本遊戲的改編：

- **光噪效應**：所有技能都會在敵人身上疊層，層數越高，每秒的衍射傷害與後續傷害加成越高。上限 12 層，每 0.9 秒傷害 `(3 + 層數 × 2.2) × 角色攻擊倍率`，之後減 1 層；告解再乘 1.6。
- **祈願**：每秒 +5，滿 120 後二選一，發動後 15 秒內不能再切換。
  - **赦罪**（輸出）：攻擊 +35%、普攻更快，對光噪目標重擊額外 +40%，啟明之鏡 +50%；發動時立即造成基礎 90 的範圍傷害。
  - **告解**（輔助）：所有光噪疊 3 倍、直接傷害 +20%、光噪持續傷害 ×1.6、默禱領域變大、持續回血、瑞吉攻擊 +15%；發動時立即造成基礎 40 的範圍傷害並疊層。

弗洛洛（鳴潮）是湮滅屬性共鳴者。湮滅侵蝕沿用上面的疊層規則。樂章與祈願共用同一條充能（每秒 +5，滿 120）。

## 美術與授權

- 菲比、瑞吉、舊敵人、道具、星光、鏡環、地板圖由 Grok 圖像生成。生成提示與後處理腳本在 `tools/pie-phoebe/`。
- v1.4 新增的六隻頭目、共鳴柱、噪卵、赫卡忒由 Google Colab 上的 Animagine XL 4.0（SDXL 動漫模型）生成，兩個 T4 工作階段並行；腳本 `tools/pie-phoebe/colab-img.py`、挑選與去背 `process_v14.py`，流程見 `tools/pie-phoebe/COLAB-ART.md`。
- 弗洛洛的 Q 版圖來自專案圖庫（備份於 `tools/pie-phoebe/refs/`），彼岸花特效 `fx_lily.png` 由 Colab 生成。
- 光暈、環、光束、彎月斬、陰影等純漸層貼圖由 `src/fxtex.js` 在執行時畫出。
- 地圖由內建 imagegen 生成，檔案為 `assets/rinascita-plaza.png`；完整提示詞在 [MAP-ART.md](./MAP-ART.md)。
- 音效：菲比與瑞吉叫聲是真實取樣（`assets/audio/`），其餘音效由 WebAudio 即時合成。只有菲比會喊「菲比啾比」；弗洛洛沒有語音。
  - 菲比：`phoebe_1..4.mp3`，一般施法不播放，僅在開場、擊敗主線頭目與勝利時嘗試播放；共用 12 秒間隔。
  - 瑞吉：`reggie_1..4.mp3`，各是連續三聲「嗷、嗷、嗷」，張嘴吼起手和環繞滑行出發時各叫一次。
- 版權：兩種叫聲都沒有取得授權。菲比叫聲取自庫洛遊戲《鳴潮》團子的語音，瑞吉叫聲取自 YouTube 上的海獅影片，都是別人上傳的公開影片切片。公開上線前請自行評估；不想用就清空 `assets/audio/manifest.json` 對應的陣列，會退回合成音。

## 程式結構

| 檔案 | 內容 |
| --- | --- |
| `src/main.js` | 啟動、鍵盤／觸控輸入、主迴圈、SDK |
| `src/game.js` | 世界狀態、武器、角色技能、瑞吉、敵人、危險區、渲染 |
| `src/bosses.js` | 六隻頭目的 AI 與機制 |
| `src/data.js` | 角色、技能、被動、敵人、頭目時間表、連攜設定 |
| `src/skills.js`、`src/balance.js` | 技能與瑞吉數值、平衡倍率（由校準腳本產生）、廣場邊界 |
| `src/gfx.js` | InstancedMesh 看板與地面貼花 |
| `src/ui.js`、`style.css` | HUD、角色選擇與各畫面 |
| `src/audio.js` | 合成音效 |

測試用：網址加 `?bot=1` 會由機器人自動遊玩（機器人會躲預警區、光束與彈幕）；`window.__pie` 可取得遊戲物件。

## 測試與量測

- 規則回歸測試：`node --test tests/pie-phoebe.test.mjs`；音效冷卻：`node tests/pie-phoebe-audio.test.mjs`。
- 瀏覽器測試：先以 `python3 -m http.server 18766 --bind 127.0.0.1 --directory site` 開啟本機服務，再執行 `node tests/pie-phoebe-browser.cjs`（可用 `PLAYWRIGHT_MODULE`、`PLAYWRIGHT_CHROMIUM_EXECUTABLE`、`PHOEBE_TEST_URL` 指定位置；本機開發需在網址加 `?mock=1&content=<服務網址>`）。涵蓋六隻頭目渲染、弗洛洛整局、亮度按鈕、角色選擇、手機拖曳與選卡。
- 技能平衡量測：`node tools/pie-phoebe/balance.mjs [--char phrolova --ref tools/pie-phoebe/balance-ref-phoebe.json]`，約一分鐘。校準：`node tools/pie-phoebe/calibrate.mjs`。
- 頭目戰模擬：`node tools/pie-phoebe/boss-sim.mjs --mobs 0.4`。整局模擬：`node tools/pie-phoebe/run-sim.mjs --char phrolova`。機器人遠不如真人會處理雜兵，這些數字只用來比較版本與發現極端問題，不是通關率承諾。
