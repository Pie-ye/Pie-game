# 派派鎮（PIE PLAZA）

星露谷風格的像素多人小鎮。登入後直接進入唯一的共用大廳（廣場），所有人在同一個空間走動、打字聊天。
帳號沿用股票大亂鬥的共用登入；沒登入也能單機逛。

## 地區

| 地區 | 說明 | 誰看得到 |
| --- | --- | --- |
| 廣場 | 出生點。中央是菲比啾比女神噴水池，東南角是瑞吉海獅劇場。西橋通往自己的農場，東橋通往商店街。 | 所有人 |
| 商店街 | 北邊六間店面向主街，中央石板市集與大樹，南邊住宅巷。四位居民在街上走動。 | 所有人 |
| 店內 | 雜貨店、麵包店、餐館、鐵匠鋪、木匠屋、診所。店主站在櫃台後，可隔著櫃台對話。 | 同一間店的人 |
| 我的農場 | 自己的小屋、出貨箱、信箱、池塘；田地長滿雜草、石頭、樹枝和樹樁。 | 自己，以及獲准拜訪／共同耕作的人 |
| 我的小屋 | 室內，可以擺家具、換地板和牆紙。 | 自己，以及獲准拜訪的人 |

## 新功能（v2）

- **捏臉**：第一次進來會先捏臉；之後按左下角「捏臉」。13 種臉型與髮型，加上髮色、膚色、上衣、褲子顏色，其他玩家看得到。
- **小屋自訂外觀**：農場小屋旁的「小屋設計」告示牌，或找商店街的木匠蘿蘋。五種樣式、七種屋頂色、六種牆面色、門前四格院子擺設。
- **定時活動**（台北時間，所有人一致）：早市 07–10（山姆的攤位種子八折）、瑞吉海獅秀 10–11／15–16／19–20、釣魚大賽 12–13 與 18–19（金色鯉魚較易出現，漁獲會公布在聊天室）、營火晚會 20–23（廣場西南草地的營火與燈串）、週末花祭 09–21。左下角「活動」或商店街、廣場的公告欄可看今天的活動表。
- **日夜**：依台北時間，黃昏偏橘、晚上變暗，路燈、營火、燈串會發光。
- **種菜**：六種作物（小麥、紅蘿蔔、甜菜、番茄、草莓、南瓜），在雜貨店用金幣買種子，第 7 格種子、Q 切換種類；收成後放進出貨箱換金幣。開局有 100 G 與一些種子。
- **釣魚**：第 6 格釣竿，面向水邊（廣場的海、農場池塘）按空白鍵拋竿，浮標下沉時再按一次提竿，接著按住空白鍵讓綠色捕捉條罩住魚，進度滿就釣到。八種魚依地點與時段出現。

## 社交（v3）

- **拜訪家園**：左下角「拜訪」列出線上鎮民、好友與鎮民名冊（開放拜訪的家園，依讚數排序）。也可以點別的玩家打開名片。主人不在線上也能逛他的農場與小屋。
- **開放設定**：在「拜訪」面板勾選是否開放自己的家園；預設開放，取消後立刻不能被拜訪。給別人看的只有田地、小屋與外觀，金幣、背包、種子不公開。
- **訪客能做的事**：在主人的信箱前按 E 可以稱讚（每家每天一次）、留言、從背包送一個作物或魚、加好友；可以用澆水壺幫忙澆水；可以在主人的池塘釣魚。其他工具只有共同耕作夥伴能用。
- **共同耕作**：在拜訪名冊或玩家名片打開「共耕」，對方會收到邀請。答應後可以在對方的農場用鋤頭、播種、收成（伺服器檢查權限，訪客改不到別人的存檔）。
- **跳蚤市場**：左下角「市場」，或商店街市集南邊的攤位按 E。上架作物、魚或材料，別人用遊戲金幣買；成交由伺服器扣款入帳，賣家會收到系統信。
- **信箱**：左下角「信箱」，有新信會顯示數字。稱讚收下後累積在名片上，禮物收下後放進背包，留言可以直接回訪。系統信還有成交通知與共耕邀請。
- **表情**：T 或左下角「表情」，十種表情泡泡，同一區的人都看得到；玩家名片的「打招呼」會揮手並在聊天室打招呼。

## 原創地標（v4）

- **菲比啾比女神噴水池**：廣場中央。按 E 投 10 G 許願，有機會得到金幣、種子或金色鯉魚。
- **瑞吉海獅劇場**：廣場東南角海邊。表演時間瑞吉會頂球、跳躍；帶一條魚去餵牠，會回送種子。

## 伺服器存檔（v4）

登入後，農場、金幣、背包、種子、小屋、外觀、社交設定都由伺服器說了算（`server/games/plaza.py`）。瀏覽器只送操作、套用回覆與推播。右上角顯示「🖥 伺服器存檔」。換裝置登入同一帳號會載入同一份。沒登入是訪客試玩，規則相同，重新整理就消失。金幣是遊戲內的，和股票大亂鬥的金幣無關。升級工具、看診還沒有功能。

## 操作

- **WASD／方向鍵**或**點地面**走路；走向門口（↑）進屋，走上門墊（↓）出門。
- **E**：對話、看告示牌；對話中按 E、空白或點對話框跳下一句。
- **1–8**：選工具；**空白鍵**或**點身邊的格子**：使用工具。
- **Enter**：聊天；**Esc**：關閉對話、面板、裝潢模式。

## 農場

| 工具 | 用途 |
| --- | --- |
| 斧頭 | 樹枝 1 下、樹樁 4 下，得到木材 |
| 釣竿 | 面向水邊拋竿，見上方說明 |
| 十字鎬 | 石頭 2 下，得到石頭 |
| 鐮刀 | 雜草 1 下得到纖維；收成成熟作物 |
| 鋤頭 | 翻土 |
| 澆水壺 | 澆濕耕地 |
| 種子 | 種在翻過的土上；Q 切換種類 |

作物澆水後 45 秒長一階，每階都要再澆水，第 4 階成熟。雜物分布由帳號 id 決定。
小屋旁的「小屋設計」告示牌可換五種外觀。在小屋裡選第 8 格（槌子）進入裝潢模式。

## 多人

只有一個共用大廳「廣場大廳」。後端每間上限 16 人，滿了才開分流；一個人時每 6 秒併到人更多的同名房。

| 訊息 | 內容 |
| --- | --- |
| `{k:'p', p:[x,y], a:'town'}` | 位置與所在地區（`plaza`、`town`、`shop:<id>`、`farm:<id>`、`house:<id>`） |
| `{k:'c', t:'文字'}` | 聊天，最多 120 字，0.8 秒一則 |
| `{k:'l', l:[5 個整數]}` | 外觀（臉型、髮色、膚色、上衣、褲子），收到一律檢查範圍 |
| `{k:'f', f:'carp', s:42}` | 釣魚大賽期間的漁獲公告 |
| `{k:'m', e:0–9}` | 表情 |
| `{k:'r'}` | 有人餵了瑞吉，同一廣場的人看到牠跳起來 |

只畫同一地區的人；聊天全鎮都看得到，泡泡只在同地區出現。收到的文字一律清掉控制字元、只用 `textContent` 顯示。

## 程式

```
src/main.js            輸入、區域切換、主迴圈（只送操作、套用伺服器回覆）
src/logic.js           移動、鏡頭、聊天檢查（純函式）
src/net.js             單一大廳連線、位置與聊天、轉送 client.game
src/game/api.js        遊戲操作入口：登入走伺服器，訪客用本機沙盒
src/game/mirror.js     把伺服器精簡資料還原成前端農場物件
src/store.js           送給伺服器的裝潢格式轉換
src/ui/market.js       跳蚤市場面板
src/social/home.js     家園快照、名冊名片、社交設定、信件檢查（純函式）
src/audio.js           音樂、環境音、腳步聲、工具聲、菲比／瑞吉語音
src/engine/atlas.js    圖集（由 tools/pie-plaza/build_atlas.py 產生，含門口位置）
src/engine/grid.js     地形格
src/engine/autotile.js 四方向自動接圖
src/engine/world.js    物件、碰撞、傳送點、互動
src/engine/ground.js   地面合成（草地、土路、石板、室內地板牆紙、耕地）
src/engine/render.js   鏡頭、y 排序、名牌、對話泡泡
src/maps/              廣場、商店街、農場、室內、NPC 資料
src/farm/state.js      雜物、耕地、作物、背包（純函式）
src/house/catalog.js   家具、地板、牆紙、擺放規則（純函式）
src/ui/                對話框、工具列與時鐘、捏臉、釣魚小遊戲、商店、公告欄、裝潢、小屋、拜訪與市場面板
src/avatar/look.js     捏臉資料與換色（純函式）
src/fish/fishing.js    魚種、抽魚、釣魚小遊戲物理（純函式）
src/events/            活動時間表與日夜（schedule.js）、活動擺設與光源（effects.js）
src/house/exterior.js  小屋外觀選項
src/engine/bodies.js   捏臉底版各區域顏色（由 build_bodies.py 產生）
```

## 測試與工具

- `node --test tests/pie-plaza.test.mjs`：地圖連通（每個傳送點走得到、每個 NPC 能對話）、農場、裝潢規則。
- `python3 -m pytest server/tests/test_plaza.py`：伺服器規則、權限、市場搶購、JS/Python 雜物分布一致。
- `python3 tools/pie-plaza/harness.py`：雙人連線與聊天（假 SDK）。
- `python3 tools/pie-plaza/play_test.py`：訪客試玩：農場工具、進出門、對話、小屋樣式、裝潢。
- `python3 tools/pie-plaza/tour.py`：各地區截圖。
- `python3 tools/pie-plaza/server_e2e.py`：真伺服器端到端（兩個帳號：存檔、拜訪、共耕、跳蚤市場、送禮、噴水池與海獅、防偽造）。
- `python3 -I tools/pie-plaza/build_atlas.py` 重產圖集；`atlas_sheet.py` 印目錄圖檢查裁切。
- `build_bodies.py` 產生捏臉底版；`process_art.py` 處理 grok 生成圖（簡報在 `tools/pie-plaza/art/`，地標在 `art/show/`）。
- 伺服器規則：`server/games/plaza.py`、`plaza_logic.py`；JS 規則匯出 `tools/pie-plaza/export_rules.mjs` → `server/games/plaza_rules.json`。
