# 派派鎮（PIE PLAZA）

星露谷風格的像素多人小鎮。登入後直接進入唯一的共用大廳（廣場），所有人在同一個空間走動、打字聊天。
帳號沿用股票大亂鬥的共用登入；沒登入也能單機逛。

## 地區

| 地區 | 說明 | 誰看得到 |
| --- | --- | --- |
| 廣場 | 出生點。西橋通往自己的農場，東橋通往商店街。 | 所有人 |
| 商店街 | 北邊六間店面向主街，中央石板市集與大樹，南邊住宅巷。四位居民在街上走動。 | 所有人 |
| 店內 | 雜貨店、麵包店、餐館、鐵匠鋪、木匠屋、診所。店主站在櫃台後，可隔著櫃台對話。 | 同一間店的人 |
| 我的農場 | 自己的小屋、出貨箱、信箱、池塘；田地長滿雜草、石頭、樹枝和樹樁。 | 只有自己 |
| 我的小屋 | 室內，可以擺家具、換地板和牆紙。 | 只有自己 |

## 新功能（v2）

- **捏臉**：第一次進來會先捏臉；之後按左下角「捏臉」。13 種臉型與髮型，加上髮色、膚色、上衣、褲子顏色，其他玩家看得到。
- **小屋自訂外觀**：農場小屋旁的「小屋設計」告示牌，或找商店街的木匠蘿蘋。五種樣式、七種屋頂色、六種牆面色、門前四格院子擺設。
- **定時活動**（台北時間，所有人一致）：早市 07–10（山姆的攤位種子八折）、釣魚大賽 12–13 與 18–19（金色鯉魚較易出現，漁獲會公布在聊天室）、營火晚會 20–23（廣場營火與燈串）、週末花祭 09–21。左下角「活動」或商店街、廣場的公告欄可看今天的活動表。
- **日夜**：依台北時間，黃昏偏橘、晚上變暗，路燈、營火、燈串會發光。
- **種菜**：六種作物（小麥、紅蘿蔔、甜菜、番茄、草莓、南瓜），在雜貨店用金幣買種子，第 7 格種子、Q 切換種類；收成後放進出貨箱換金幣。開局有 100 G 與一些種子。
- **釣魚**：第 6 格釣竿，面向水邊（廣場的海、農場池塘）按空白鍵拋竿，浮標下沉時再按一次提竿，接著按住空白鍵讓綠色捕捉條罩住魚，進度滿就釣到。八種魚依地點與時段出現。

## 操作

- **WASD／方向鍵**或**點地面**走路；走向門口（↑）進屋，走上門墊（↓）出門。
- **E**：對話、看告示牌；對話中按 E、空白或點對話框跳下一句。
- **1–8**：選工具；**空白鍵**或**點身邊的格子**：使用工具。
- **Enter**：聊天；**Esc**：關閉對話、面板、裝潢模式。

## 農場

| 工具 | 用途 |
| --- | --- |
| 斧頭 | 樹枝 1 下、樹樁 4 下，得到木材 |
| 釣竿 | 面向水邊拋竿，見上方說明 |
| 十字鎬 | 石頭 2 下，得到石頭 |
| 鐮刀 | 雜草 1 下得到纖維；收成成熟作物 |
| 鋤頭 | 翻土 |
| 澆水壺 | 澆濕耕地 |
| 種子 | 種在翻過的土上；Q 切換種類 |

作物澆水後 45 秒長一階，每階都要再澆水，第 4 階成熟。雜物分布由帳號 id 決定。
小屋旁的「小屋設計」告示牌可換五種外觀。在小屋裡選第 8 格（槌子）進入裝潢模式。

農場、金幣、外觀與小屋登入後存在雲端（平台的 SDK `client.storage`，伺服器依帳號存放），換裝置會自動載入；本機 localStorage 是快取與離線備援。登入時雲端與本機比較最後修改時間，新的贏；兩台同時修改時以版本號偵測衝突，較新的留下。右上角 ☁ 顯示同步狀態。金幣是遊戲內的，和股票大亂鬥的金幣無關。升級工具、看診還沒有功能。

## 多人

只有一個共用大廳「廣場大廳」。後端每間上限 16 人，滿了才開分流；一個人時每 6 秒併到人更多的同名房。

| 訊息 | 內容 |
| --- | --- |
| `{k:'p', p:[x,y], a:'town'}` | 位置與所在地區（`plaza`、`town`、`shop:<id>`、`farm:<id>`、`house:<id>`） |
| `{k:'c', t:'文字'}` | 聊天，最多 120 字，0.8 秒一則 |
| `{k:'l', l:[5 個整數]}` | 外觀（臉型、髮色、膚色、上衣、褲子），收到一律檢查範圍 |
| `{k:'f', f:'carp', s:42}` | 釣魚大賽期間的漁獲公告 |

只畫同一地區的人；聊天全鎮都看得到，泡泡只在同地區出現。收到的文字一律清掉控制字元、只用 `textContent` 顯示。

## 程式

```
src/main.js            輸入、區域切換、主迴圈
src/logic.js           移動、鏡頭、聊天檢查（純函式）
src/net.js             單一大廳連線、位置與聊天
src/store.js           localStorage 存檔（本機快取）
src/cloud.js           雲端存檔同步（比對、延遲上傳、衝突處理）
src/audio.js           音樂、環境音、腳步聲、工具聲
src/engine/atlas.js    圖集（由 tools/pie-plaza/build_atlas.py 產生，含門口位置）
src/engine/grid.js     地形格
src/engine/autotile.js 四方向自動接圖
src/engine/world.js    物件、碰撞、傳送點、互動
src/engine/ground.js   地面合成（草地、土路、石板、室內地板牆紙、耕地）
src/engine/render.js   鏡頭、y 排序、名牌、對話泡泡
src/maps/              廣場、商店街、農場、室內、NPC 資料
src/farm/state.js      雜物、耕地、作物、背包（純函式）
src/house/catalog.js   家具、地板、牆紙、擺放規則（純函式）
src/ui/                對話框、工具列與時鐘、捏臉、釣魚小遊戲、商店、公告欄、裝潢與小屋面板
src/avatar/look.js     捏臉資料與換色（純函式）
src/fish/fishing.js    魚種、抽魚、釣魚小遊戲物理（純函式）
src/events/            活動時間表與日夜（schedule.js）、活動擺設與光源（effects.js）
src/house/exterior.js  小屋外觀選項
src/engine/bodies.js   捏臉底版各區域顏色（由 build_bodies.py 產生）
```

## 測試與工具

- `node --test tests/pie-plaza.test.mjs`：地圖連通（每個傳送點走得到、每個 NPC 能對話）、農場、裝潢規則。
- `python3 tools/pie-plaza/harness.py`：雙人連線與聊天（假 SDK）。
- `python3 tools/pie-plaza/play_test.py`：農場工具、進出門、對話、小屋樣式、裝潢。
- `python3 tools/pie-plaza/tour.py`：各地區截圖。
- `python3 tools/pie-plaza/cloud_e2e.py`：雲端存檔端到端（真的開發伺服器＋SQLite＋SDK，兩個瀏覽器當兩台裝置）。
- `python3 -I tools/pie-plaza/build_atlas.py` 重產圖集；`atlas_sheet.py` 印目錄圖檢查裁切。
- `build_bodies.py` 產生捏臉底版；`process_art.py` 處理 grok 生成圖（簡報在 `tools/pie-plaza/art/`）。
